# Bug: the display never showed a recognition

**Symptom:** Kafka-WebApp logged `[ERROR] Image server error: 422, Unprocessable Content` for every Kafka message, and the screen never showed a face.

**Root cause:** Kafka-WebApp posted `json.dumps(...)` with `requests.post(data=...)`, which sends no `Content-Type`. The display server, on FastAPI 0.162.0, refuses that body: `Input should be a valid dictionary or object to extract fields from`.

**Fix:** Kafka-WebApp v0.1.2 posts with `json=`, which sets `Content-Type: application/json` (hamza-aziz-ai/Kafka-WebApp#3). This repo pins v0.1.2 by digest.

**Test:** against the live display on the deployment host, `json=` returned 200 with the enrolled photo; the old call returned 422.

**Not tested:** a real camera recognition shown on the screen.
